# Employee Management Mini System

## Overview

Employee Management Mini System is a full-stack web application built using React and Java Spring Boot.

The application allows users to login and manage employee information through a REST API based architecture.


## Features

### Authentication

- User Login
- Username and Password Validation


### Employee Management

- Create Employee
- View Employees
- View Employee Details
- Update Employee
- Delete Employee


## Technology Stack


### Frontend

- React 18
- JavaScript
- Axios
- React Router
- Vite


### Backend

- Java 17
- Spring Boot 3
- Spring Web
- Spring Data JPA
- Hibernate


### Database

- MySQL
